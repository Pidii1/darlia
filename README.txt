Darlia website (GitHub + Vercel)
- Put everything in this folder into a GitHub repo named darlia, then import it on vercel.com. No build step, no database needed.
- Every file here is under 20 MB, so GitHub's "upload files" page accepts them (the erase model is split in two parts on purpose).
- The apps are NOT kept here (too big). Upload them to a GitHub Release instead, with these exact names:
    Darlia.apk          (Android)
    Darlia-Setup.msi    (Windows)
  The "Get the app" buttons on the home page point to releases/latest/download/<name>.
